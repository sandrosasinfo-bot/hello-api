# Hello API - Painel de Clima e Hora

Projeto simples em Node.js usando Express que exibe a data, hora atualizada em tempo real e o clima de São Paulo.

## Como rodar localmente

1. Clone o repositório  
2. Rode `npm install` para instalar dependências  
3. Rode `npm start` ou `node index.js`  
4. Acesse `http://localhost:3000` no navegador  

## Deploy

Este projeto pode ser facilmente publicado em serviços como Render ou Heroku. Configure a branch principal para deploy automático.

## Tecnologias

- Node.js  
- Express  
- Axios  
- OpenWeatherMap API
